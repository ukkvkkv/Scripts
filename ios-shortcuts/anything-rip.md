# Команда iOS «Rip» — скачивание через anything.rip из меню «Поделиться»

## Как устроен сайт

- Ссылку можно передать прямо в адресе, обработка стартует сама:
  `https://anything.rip/#<ссылка>` или `https://anything.rip/?url=<ссылка>`.
- Сам запрос на обработку защищён Cloudflare Turnstile (в коде страницы есть
  `window.TS = "0x4AAAAAAFFwbNBRGwBIZHIR"` — это ключ капчи), а логика спрятана в
  обфусцированном скрипте. Поэтому «Получить содержимое URL» из «Команд» не может
  запустить обработку сам — нужен браузер, где капча проходит незаметно.
- Готовый результат — прямая ссылка `https://anything.rip/dl/<id>` (кнопка **copy link**).
  Сайт прямо пишет, что она для менеджеров загрузок и curl, то есть качается без браузера.

Отсюда схема: браузер делает обработку, команда сама скачивает и сохраняет файл.

## Команда «Rip» (почти полностью автоматическая)

Пользователь: **Поделиться → Rip** → в открывшемся Safari нажать **copy link** →
вернуться назад (кнопка «◀» слева вверху) → файл сам скачается и сохранится в «Фото».

### Сборка

1. «Команды» → **+** → имя `Rip`.
2. **ⓘ** → включить **«Показывать в листе Поделиться»**; типы: URL-адреса, Текст,
   Веб-страницы Safari. «Если нет входных данных» → **Получить буфер обмена**.
3. Действия:

   | # | Действие | Настройка |
   |---|----------|-----------|
   | 1 | **Получить URL-адреса из входных данных** | `Входные данные быстрой команды` |
   | 2 | **Получить объект из списка** | `Первый объект` |
   | 3 | **Текст** | `https://anything.rip/#` + `Объект из списка` |
   | 4 | **Открыть URL-адреса** | `Текст` |
   | 5 | **Ждать возврата** | — |
   | 6 | **Получить буфер обмена** | — |
   | 7 | **Если** | `Буфер обмена` **содержит** `anything.rip/dl/` |
   | 8 | ↳ **Получить содержимое URL** | `Буфер обмена` (метод GET) |
   | 9 | ↳ **Сохранить в фотоальбом** | `Содержимое URL`, альбом «Недавние» |
   | 10 | **Иначе** → **Показать уведомление** | `Ссылка не скопирована` |
   | 11 | **Конец «Если»** | |

   Для файлов, которые не фото/видео (архивы, музыка, документы), в шаге 9 вместо
   «Сохранить в фотоальбом» используй **«Сохранить файл»** (в «Файлы»), или
   добавь внутрь ещё одно «Если»: `Содержимое URL` **тип** `Видео/Изображение`.

### Если «Ждать возврата» не срабатывает из листа «Поделиться»

Раздели на две команды:

- **Rip** — шаги 1–4.
- **Rip: сохранить** — шаги 6–11. Запускай после **copy link** из виджета,
  через «Касание задней панели» или с экрана «Команд».
