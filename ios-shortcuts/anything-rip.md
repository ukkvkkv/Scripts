# Команда iOS «Rip» — открыть ссылку в anything.rip из меню «Поделиться»

Сайт сам подхватывает ссылку из адреса `https://anything.rip/#<ссылка>` и сразу её обрабатывает.
Команда просто открывает этот адрес — остаётся нажать **download**.

## Сборка («Команды»)

1. **+** → имя `Rip`.
2. **ⓘ** → **«Показывать в листе Поделиться»**; типы: URL-адреса, Текст, Веб-страницы Safari.
3. Действия:
   1. **Получить URL-адреса из** `Входные данные быстрой команды`
   2. **Получить объект из списка** → `Первый объект`
   3. **Текст** → `https://anything.rip/#` + `Объект из списка` (без пробела)
   4. **Открыть URL-адреса** → `Текст`

Использование: **Поделиться → Rip → download**.
