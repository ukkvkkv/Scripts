# Команда iOS «Rip» — скачивание через anything.rip из меню «Поделиться»

Сайт https://anything.rip принимает ссылку прямо в адресе и сразу начинает её обрабатывать:

```
https://anything.rip/#<ссылка>
https://anything.rip/?url=<ссылка>
```

Команда берёт то, чем поделились, подставляет в этот адрес и открывает его в Safari.
Остаётся нажать **download**.

## Сборка (приложение «Команды»)

1. **+** → новая команда, назови её `Rip`.
2. Внизу нажми **ⓘ** → включи **«Показывать в листе Поделиться»**.
   Вверху в блоке «Получать … из листа Поделиться» оставь только **URL-адреса**, **Текст** и **Веб-страницы Safari**.
   «Если нет входных данных» → **Получить буфер обмена** (тогда команду можно запустить и вручную со скопированной ссылкой).
3. Добавь действия по порядку:

   | # | Действие | Настройка |
   |---|----------|-----------|
   | 1 | **Получить URL-адреса из входных данных** | вход: `Входные данные быстрой команды` |
   | 2 | **Получить объект из списка** | `Первый объект` из `URL-адреса` |
   | 3 | **Текст** | `https://anything.rip/#` + переменная `Объект из списка` (без пробелов) |
   | 4 | **Открыть URL-адреса** | вход: `Текст` |

4. Готово. В любом приложении: **Поделиться** → **Rip** → откроется anything.rip с уже запущенной обработкой → **download**.

## Если ссылка обрезается

Ссылки с несколькими параметрами (`?a=1&b=2`) через `#` передаются целиком.
Если какой-то сайт всё же не открывается, замени шаг 3 на два действия:

- **Закодировать URL** (действие «Кодировать URL») для `Объект из списка`;
- **Текст**: `https://anything.rip/?url=` + `Закодированный текст`.

## Сохранение сразу в «Фото» (необязательно)

После нажатия **download** Safari сохраняет файл в «Файлы → Загрузки».
Чтобы видео попало в галерею: открой файл в «Файлах» → **Поделиться** → **Сохранить видео**.
